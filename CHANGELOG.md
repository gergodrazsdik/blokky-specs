# Changelog

All notable changes to the Blokky language specification are documented in this file. Each entry is a spec version.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the specification adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

The language 1.0 is in draft: drafts are tagged `v1.0.0-draft.N` and are not listed here. The first entry will be `1.0.0`, listing the language's major features; decisions along the way are in [`adr/`](adr/README.md).
